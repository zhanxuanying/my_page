# 在线写作使用说明

[打开轩颖的写作间](https://xuanying-homepage.xuanying-personal-homepage.workers.dev/admin) · [查看博客](https://xuanying-homepage.xuanying-personal-homepage.workers.dev/blog)

## 登录

使用初始化时配置的管理员邮箱。初始随机密码保存在配置此项目的 Mac 的“钥匙串访问”中，项目名称为 **Xuanying writing admin**，账户为管理员邮箱。查看该条目的密码需要本机验证。密码没有记录在仓库里。

登录后可在个人资料中修改邮箱、显示名称和密码。后台关闭公开注册，连续输错五次会暂时锁定十五分钟。

## 写一篇文章

1. 在首页点“写一篇新笔记”，或打开“文章”后新建。
2. 填写标题、正文。工具栏支持标题、粗体、斜体、列表、引用、链接和图片。
3. 在侧栏设置分类、标签和封面。摘要留空会自动从正文提取；阅读时间自动计算。
4. 编辑器每三秒尝试自动保存；切换或关闭页面前，确认保存状态已完成，也可手动保存草稿。
5. 点“预览”检查阅读效果。预览需要管理员登录，其他人无法看到草稿。
6. 准备好后点“发布”。刷新博客和个人主页即可看到更新，无须重新部署网站。

文章网址标识会自动生成，也可使用小写字母、数字和短横线填写，例如 `a-little-happy-day`。发布后尽量保持不变，以免以前的链接失效。

三篇迁移内容保留“示例文章”标记；换成自己的内容后可取消该标记。

## 修改、下架和历史

已发布文章的未发布修改会保存为草稿，读者继续看到上一次正式发布的版本。再次发布后，读者才能看到修改。

需要下架时使用文章菜单里的取消发布功能。删除文章会删除当前内容，适合明确不再需要的记录。后台的版本页面保留每篇文章最多三十个版本，可查看并恢复以前的内容。

将“发布时间”设为未来，并发布文章后，访客会在该时间到达后看到文章。这里根据访问时的服务器时间判断，无须后台定时任务。注意日期控件显示的本地时区。

## 图片

在“图片库”上传素材，填写图片描述，再在文章中选择封面或插入正文。支持 PNG、JPEG、WebP、GIF，单张最大 5 MB，中文文件名可以直接上传。

图片保存在 Supabase Storage，重启或重新部署不会丢失。图片库属于公开素材库，包括草稿中使用的图片；私人文件不要放入其中。删除图片会影响所有引用它的文章，先确认引用情况。

## 阅读

博客支持按分类筛选和搜索标题、摘要、正文；文章页提供目录跳转、阅读进度、字号切换和复制分享链接。页尾可继续阅读前后篇，也可订阅 `/feed.xml`。

## 密码找回

当前未配置发信服务，邮件找回密码暂不可用。仍能登录时在个人资料中改密码；忘记密码时，可在有本地数据库配置的 Mac 上运行：

```sh
npm run admin:account -- your-email@example.com --reset
```

命令只用于此站点的单管理员维护，会生成新密码并更新上述钥匙串条目，不会把密码打印出来。如果以后增加多名管理员，需要先扩展此恢复工具。
