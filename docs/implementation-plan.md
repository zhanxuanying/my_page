## 设计与范围

- 面向 GitHub Pages 的纯静态单页，无框架、无运行时依赖。
- 樱花粉、奶白、深梅色文字；兔子主视觉、精致网格、轻量进入和悬停动画。
- 个人介绍仅使用提供的信息：占轩颖、21 岁、女、文员、喜欢王菲与兔子。
- 实用工具：25 分钟专注计时、设备本地待办、实时字数统计。
- 博客笔记：3 篇标明为示例的实用笔记，弹窗阅读。
- 动画尊重减少动态效果偏好；移动端导航、键盘操作、弹窗焦点均可用。
