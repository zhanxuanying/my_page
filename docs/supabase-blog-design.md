# Supabase 博客接入

用户确认范围：先接入博客笔记。保持现有粉色页面、三种文章封面及阅读弹窗；待办仍在本机保存。

Supabase 的 `public.blog_posts` 存储文章。编辑在 Supabase Table Editor 完成，浏览器通过 Data API 读取已发布、发布时间已到的文章。启用 RLS，并明确撤销访客和普通登录用户的写入权限。正文使用纯文本及少量 Markdown（标题、列表、引用）；页面转义所有数据库文本。

没有配置时继续显示三篇本地示例。配置成功后数据库是唯一内容来源：空库显示空状态；网络失败显示重试入口，不恢复已下架文章。前端只接受 publishable key。数据库管理令牌、密码不进入仓库或发布文件。

验收：真实 PostgreSQL 引擎验证权限；前端测试覆盖安全渲染、空数据、请求失败和翻页；桌面和手机验证阅读、重试及原有工具；登录后再执行云端迁移、检查实际 API 并发布。
